# TML Fantasy League Intelligence

This repository contains only the public informational landing page for TML Fantasy League Intelligence, a private, non-commercial fantasy-football analytics project.

The actual analytical application and all private league data are not included in this repository. The landing page has no API integration, authentication, data collection, analytics, cookies, or external dependencies.

## Preview locally

Open `index.html` directly in a web browser. No installation, development server, or build step is required.

## Publish with GitHub Pages

After creating a GitHub repository and pushing this repository's `main` branch:

1. Open the repository on GitHub.
2. Select **Settings**, then **Pages**.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
4. Select the `main` branch and the `/ (root)` folder.
5. Select **Save**.

GitHub Pages will publish the static files from the repository root. The site is intentionally framework-free and requires no build configuration.
